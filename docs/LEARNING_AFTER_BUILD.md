# Learning AEGIS After Building

Do not attempt to memorize the project from generated documentation alone. Learn by subsystem:

1. Re-derive every data structure and complexity claim in M1.
2. Reproduce golden order-book examples by hand.
3. Explain futures expiry, rolls and adjustment consequences from M2.
4. Reimplement rolling mean/variance and P&L reconciliation independently.
5. Derive each strategy hypothesis, statistical test and failure condition.
6. Trace one order through strategy → risk → OMS → exchange → fill → portfolio.
7. Break each risk limit deliberately and explain the response.
8. Recreate walk-forward and leakage tests.
9. Explain every benchmark timestamp and percentile.
10. Run Decision Arena analyses and distinguish decision quality from outcome.

For CV defense, select five end-to-end scenarios and be able to explain every line of data, code path, assumption, failure mode and result without Claude.
